📺 Bilibili 解析下载

支持 bilibili.com/video/BV...、av...、b23.tv 短链等格式
⚙ 解析 API 设置（直接下载需要）
选择"自建服务器"并填入地址，可实现服务器端 yt-dlp 下载，速度最快最稳定
自建服务部署：将 server/ 目录上传到你的云服务器， 运行 pip install -r requirements.txt && pip install yt-dlp && python app.py
🔑 B站 Cookie 设置（解锁 1080P+）
获取方法：浏览器打开 bilibili.com 并登录 → 按 F12 打开开发者工具 → Application → Cookies → https://www.bilibili.com → 复制 SESSDATA 的值粘贴到下方
